# promptEngineering_week1
# Prompt Engineering Lab – LLM API Connectivity

## Aim

To establish a working environment for prompt engineering by configuring an API key, installing the required libraries, and communicating with a Large Language Model (LLM) through a simple Python program.

## Problem Statement

The objective of this experiment is to connect a Python program with an LLM API, send a simple prompt, receive the generated response, and handle basic errors such as a missing API key or API/network failure.

## Prompt Used

> What is prompt engineering? Answer in one sentence.

## Technologies Used

* Python
* Groq API
* Groq Python SDK
* python-dotenv
* Large Language Model (LLM)

## Project Structure

```text
PromptEngineeringLab/
│
├── connectivity.py
├── requirements.txt
├── .env.example
├── .gitignore
└── README.md
```

## Installation

Install the required Python libraries using:

```bash
pip install -r requirements.txt
```

## API Key Setup

Create a `.env` file in the project folder and add your Groq API key:

```env
GROQ_API_KEY=your-groq-api-key
```

**Important:** Never upload the real API key to GitHub.

The `.env` file is excluded using `.gitignore`.

## Execution

Run the Python program using:

```bash
python connectivity.py
```

## Expected Output

```text
Environment ready. Sending prompt...

Prompt: What is prompt engineering? Answer in one sentence.

Response:
Prompt engineering is the process of designing effective instructions to guide an AI model to produce the desired output.
```

The exact response may vary because it is generated by the LLM.

## Error Handling

The program handles:

* Missing API key
* API errors
* Network errors
* Other runtime exceptions

Example:

```text
Error: GROQ_API_KEY not found in environment variables.
```

## Learning Outcome

After completing this experiment, the learner will understand how to:

* Configure an LLM API environment.
* Store API keys securely.
* Install and use required Python libraries.
* Send prompts to an LLM.
* Receive and display LLM responses.
* Handle basic API and network errors.

## Security Note

Never commit or share the real Groq API key on GitHub or in source code. Use environment variables or a secure secret-management method instead.
